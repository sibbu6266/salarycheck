# ExpenseFlow

ExpenseFlow is a front-end expense tracker project.

## Features

- User Registration
- User Login
- Password Reset Demo
- Dashboard
- Add Income
- Add Expenses
- Calculate Available Balance
- Delete Transactions
- Profile Management
- Responsive Design
- LocalStorage Data Storage

## Technologies

- HTML
- CSS
- JavaScript
- LocalStorage

## How to Run

1. Open the ExpenseFlow folder in VS Code.
2. Install the Live Server extension.
3. Open index.html.
4. Right-click and select Open with Live Server.

## Important Note

This is a front-end learning project.
It does not use a secure backend or database.
Do not enter real passwords or sensitive financial information.
